# David J. Vicente — personal academic website

A plain HTML and CSS academic website for David J. Vicente, Associate Research Professor at CIMNE Madrid and a member of the Machine Learning in Civil Engineering research group. Pages use relative links and assets so the site can be opened locally and published from the repository root with GitHub Pages.

## Pages

- `index.html` — Home and short introduction
- `research.html` — Research areas
- `publications.html` — Publications
- `projects.html` — Research projects
- `about.html` — Academic background, professional experience, scientific activities and contact
- `styles.css` — Shared layout, responsive styles and light/dark color schemes
- `assets/images/david-j-vicente.png` — Supplied profile photograph

Personal details that have not yet been provided are marked as placeholders. Replace them with verified information before publishing.

## Preview locally

Open `index.html` in a browser, or serve this folder with a static file server. No build step or external dependencies are required.

## Publish with GitHub Pages

1. Add these files to the intended GitHub repository.
2. In the repository settings, open **Pages**.
3. Select **Deploy from a branch**, choose the publication branch and the `/(root)` folder, then save.
4. Visit the URL shown in the Pages settings after deployment completes.

The site has not been committed or pushed.
